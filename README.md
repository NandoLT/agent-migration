# Agent Migration

**Session portability for Orca.**

Proyecto para importar conversaciones locales de OpenAI Codex a OpenCode 2 desde Orca, preservando los originales y verificando lo importado.

**Estado:** investigación inicial. Aún no hay plugin instalable ni se pueden importar sesiones con este proyecto.

La [nota de compatibilidad](docs/compatibility.md) recoge lo comprobado en Orca 1.4.273 y OpenCode 2.4.1, los límites de permisos y el primer experimento propuesto.
